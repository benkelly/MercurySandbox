Keys stay home

Provider keys live in the LiteLLM gateway and nowhere else. With virtual keys on, a sandbox gets one model, a budget and an expiry. With a GitHub App, it gets one repository for one hour.

Sandboxes are cattle

Read-only root, tmpfs, dropped capabilities, memory and CPU caps, a time limit, an isolated network, --rm. One repository, one task, gone when done.

One definition, four homes

The same compose file and the same controller image run on a laptop, a server, inside a Home Assistant add-on, and on Kubernetes with sandboxes as Jobs.
